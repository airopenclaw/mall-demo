🔧 强制刷新缓存

⚠️ 为什么修改没有生效？
浏览器缓存了旧的 CSS 和 JavaScript 文件。即使服务器有最新文件，浏览器也可能使用缓存。

方法 1：强制刷新（最快）

在打开 index.html 的页面按：

  • Mac: Cmd + Shift + R
  • Windows: Ctrl + Shift + R

这会强制浏览器从服务器重新加载所有文件。

方法 4：开发者工具强制刷新

  1. 打开 F12 或右键 → 检查
  2. 右键点击刷新按钮 ↻
  3. 选择 "清空缓存并硬性重新加载"

方法 5：无痕/隐私模式

使用浏览器的无痕模式，不会使用任何缓存：

  • Chrome: Cmd+Shift+N (Mac) 或 Ctrl+Shift+N (Windows)
  • Safari: 文件 → 新建无痕浏览窗口
